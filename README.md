## 📘 About the Course

**Programming for Problem Solving (PPS)** is a first-year engineering course designed to develop the ability to **think logically, analyze problems, design solutions, and implement those solutions using C programming**.

The course does not focus only on learning programming syntax. The primary objective is to develop a **problem-solving mindset**:

> **Understand the Problem → Design the Solution → Write the Program → Test → Improve**

Students will learn how to transform a problem into an algorithm, represent the solution using pseudocode and flowcharts, and finally implement and execute the solution using C.

The course gradually progresses from basic programming concepts to **functions, pointers, arrays, strings, searching, sorting, recursion, dynamic memory, structures, and file handling**.

---

## 🎯 Course Objectives

By the end of the course, students should be able to:

- Understand fundamental programming concepts.
- Analyze a problem before writing code.
- Design algorithms for solving programming problems.
- Represent solutions using **algorithms, pseudocode, and flowcharts**.
- Write, execute, and debug C programs.
- Apply decision-making and iterative constructs.
- Develop modular programs using functions.
- Understand pointers and memory.
- Organize and process data using arrays, strings, and structures.
- Apply searching and sorting techniques.
- Understand recursion and dynamic memory allocation.
- Work with files and process stored data.
- Develop systematic and efficient problem-solving approaches.

# 📚 Course Units

The course is organized into **five units**, progressing from fundamental C programming concepts to modular programming, data organization, recursion, dynamic memory, structures, and file handling.

---

## 🟦 Unit 1 — C Fundamentals and Decision Making

### Focus

Understanding the basic building blocks of C programming and developing logical decision-making skills.

### Topics Covered

- Basic data types in C
  - `int`
  - `float`
  - `char`
- Data representation
- Size and range of data types
- Choosing appropriate data types for applications
- Assignment statements
- Arithmetic expressions
- Arithmetic operators
- Evaluation of expressions
- Operator precedence
- Variables and variable manipulation
- Decision-making using:
  - `if`
  - `else if`
  - `else`
- Boolean expressions
- Logical decision-making

### Guided Practice

Students will practice:

- Tracing the execution of small C programs
- Evaluating arithmetic expressions
- Applying operator precedence
- Solving problems using variables
- Designing decision-making programs
- Working with Boolean and logical conditions

### Unit Outcome

By the end of Unit 1, students should be able to:

> **Understand basic C constructs and implement simple decision-based problem-solving programs.**
